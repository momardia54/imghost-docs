# Keyboard shortcuts

On Windows and Linux, use Ctrl where this page says Cmd.

## Everywhere

| Keys | Action |
|---|---|
| `/` or Cmd+K | Search |
| Esc | Clear the search (while typing in it), close a dialog |
| Cmd+V | Upload images from the clipboard |

## Library

| Keys | Action |
|---|---|
| Cmd+A | Select all loaded images |
| Cmd-click | Add an image to the selection, or remove it |
| Shift-click | Select a range |
| Delete or Backspace | Delete the selected images (asks first) |
| Esc | Clear the selection |

## Folder tree

| Keys | Action |
|---|---|
| Enter | Open the focused folder |
| Right arrow | Expand |
| Left arrow | Collapse |
| F2, or double-click | Rename |
| Enter / Esc while renaming | Save / cancel |

## Lightbox

| Keys | Action |
|---|---|
| Left / Right arrow | Previous / next image |
| `i` | Show or hide the details panel |
| `c` | Copy the current snippet (link, Markdown, HTML or BBCode) |
| Esc | Close |
